# 注释更新报告模板

交付时按本模板给出报告，让"自动改的部分"可核对、"待确认的部分"可一眼扫完。分级定义见 comment-update-policy.md。

## 使用原则

- **没发生的段落直接省略**，不要为了凑齐三段写"无"。全任务无注释改动时，一句话说明即可。
- L1 段落是**汇总**，不是流水账；同一类改动合并成一行，附文件与位置。
- L3 段落必须给出可直接采用的替换文本，让人工只需回答同意或不同意。
- 不编造验证结果。没跑测试就说没跑。

## 只读模式（只审查 / 只报告不改）

用户只要求审查、解释，或明确说"只报告不改"时，**不写入任何文件**。此时三段全部是提议，标题相应改写，绝不能出现"已更新""已写入"：

| 常规标题 | 只读模式标题 | 已写入文件？ |
| --- | --- | --- |
| L1 已更新 | L1 提议（未写入，授权后可直接执行） | 否 |
| L2 已更新 | L2 提议（未写入，授权后需归档原文） | 否 |
| L3 待人工确认 | L3 待人工确认（未改动） | 否 |

只读模式下 L1 段落要额外给出改动位置与依据，让人工能一次授权后批量执行。

## 模板

```markdown
## 注释更新报告

范围：<本次任务涉及的文件 / 功能 / 问题；扩大的搜索范围及原因>
任务授权：<默认分级 / 用户本次提升的授权，如"本次全权 L2">
模式：<常规（已写入）/ 只读（全部为提议，未写入）/ 含 ADR 草稿（ADR 未写入，只有草稿）>
归档：<Git 提交可回滚，或归档文件路径，或"原文见下方 L2 表">

### L1 已更新（已直接写入，供核对）

| 位置 | 改动 | 依据 |
| --- | --- | --- |
| `src/a.py:42` | 新增 {目标：复用连接；因为每次重建开销更大} | 本次实现，见 `src/a.py:30-58` |
| `src/b.ts:12` | 修正失效链接 `docs/api.md` → `docs/api-v2.md` | 目标文件已改名 |
| `src/c.py:7` | 为既有结论追加 2026-09-24 复测证据，原结论未改 | 本次新增测试 `tests/test_c.py::test_retry` |

共 <N> 条，涉及 <M> 个文件。

### L2 已更新（已写入，请复核）

| 位置 | 原文 | 改后 | 依据 | 归档 |
| --- | --- | --- | --- | --- |
| `src/d.py:88` | {待验证：断线后是否需要重连} | {已验证：断线后需重连，见 #12} | `tests/test_reconnect.py` 复现 | Git 可 diff |

如对某条不同意，`git revert` 该块或告知我逐条回退。

### L3 待人工确认（未改动，仅提议）

| # | 位置 | 现状 | 建议改为 | 为什么需要你确认 |
| --- | --- | --- | --- | --- |
| 1 | `src/e.py:15` | `# 这里必须重试三次，当年线上出事才加的` | 保留原文，仅在下方追加 `# {待确认：重试次数依据未知，2026-09-24}` | 人工书写的历史记录，无法从工作区证实 |
| 2 | `src/f.py:3` | `# #2「并发下计数会少 1」` | 建议复用 #2 而非新开 #5 | 编号复用涉及跨文件引用 |

未写入任何 L3 改动。

### 本次未处理 / 不确定项

- <发现的疑点、冲突、缺证据的判断；说明为什么这次没动>
- <未执行的验证，以及原因>
```

## 分层对应关系

| 报告段落 | 对应级别 | 已写入文件？ | 人工要做的事 |
| --- | --- | --- | --- |
| L1 已更新 | L1 | 是（只读模式为否） | 扫一眼即可，发现问题再回退 |
| L2 已更新 | L2 | 是（只读模式为否） | 逐条复核表格，不同意就回退 |
| L3 待人工确认 | L3 | 否 | 逐条回答同意 / 不同意 / 换个说法 |

## 精简示例（改动很少时）

```markdown
## 注释更新报告

范围：`src/cache.py`，仅新增缓存失效逻辑。

### L1 已更新
- `src/cache.py:31` 新增 {目标：写入即失效；因为读到脏数据的代价高于一次重建}。

### L3 待人工确认
- `src/cache.py:12` 的既有注释 `# 别动这个 TTL，压测调过的` 与新逻辑冲突。
  建议保留原文，另起一行加 `# {待确认：新失效逻辑是否已使该 TTL 失去意义，2026-09-24}`。
  你确认后我再改。

无 L2 改动。未运行测试，本次只改注释。
```
